安装指南 · Install Guide

把「财经基础英语可视化学习集」安装到桌面，像 App 一样一键打开（支持离线缓存）。

A
Android · Chrome 浏览器打开本页面 → 点地址栏右侧菜单「⋮」→ 选择「安装应用 / Install app」→ 确认安装。也可用 Chrome 地址栏出现的「安装」图标。
W
电脑 · Chrome / Edge 浏览器打开本页面 → 地址栏右侧出现「安装」⊕ 图标（或在菜单中选「安装 财经英语可视化…」）→ 确认安装，即可从桌面/开始菜单打开。
i
iPhone / iPad · Safari 浏览器打开本页面 → 点底部「分享」按钮（方框+箭头）→ 向下找到「添加到主屏幕 / Add to Home Screen」→ 点「添加」，桌面即出现应用图标。
G
GitHub Pages 部署后在浏览器直接访问部署链接即可触发安装提示；本地双击打开（file://）仅可浏览，安装按钮需要部署到 https 环境后完整生效。
